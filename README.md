# 声启旅程

声启旅程是一款面向车机连接场景的 Android 欢迎音频播放器。

## 主要功能

- 监听手机与车机之间的 USB 连接状态。
- 检测到符合条件的车机连接事件后自动播放欢迎音频，目前仅实测 CarLife 通道。
- 播放服务在后台运行，应用退到后台后仍可继续监听。
- 主界面提供手动播放、暂停、继续播放和进度显示，方便调试。
- USB 连接事件会显示在主界面，也会保存到应用内部的 `usb-events.log`。
- 支持查看、复制、导出和清理连接日志。

## 自定义音频

将音频文件放入手机内部存储的以下目录：

```text
Music/WelcomePlayer/
```

例如：

```text
Music/
└── WelcomePlayer/
    ├── 01_欢迎回来.mp3
    ├── 02_已连接车辆.mp3
    └── 03_祝您旅途愉快.mp3
```

应用会按照文件名排序依次播放。建议使用数字前缀控制播放顺序。

支持的音频格式：

- MP3
- WAV
- M4A
- AAC
- OGG
- FLAC

## 使用方式

1. 将音频文件放入 `Music/WelcomePlayer/`。
2. 安装并打开声启旅程，确认前台服务通知已经出现。
3. 连接车机，满足车机 USB 条件后会自动播放。
4. 也可以点击主界面底部的圆形播放按钮进行手动测试。

## 日志

主界面会实时显示 USB 事件。日志文件位于应用内部目录：

```text
files/usb-events.log
```

日志支持长按复制、导出和清理，用于分析不同设备的 USB 连接特征。

## 注意事项

- 请使用支持数据传输的 USB 线。
- 国产 Android 系统请在系统设置中将声启旅程的电量使用策略设置为“不限制”或“允许后台运行”，关闭电池优化和后台活动限制。
- 请允许声启旅程自启动；打开应用后，在最近任务界面将声启旅程锁定，避免清理后台时被系统结束。
- 保持前台服务通知显示。只有完成上述后台设置，应用退到后台后才能按预期监听 USB 事件并自动播放。
- 当前仅实测 CarLife 通道，其他车机互联协议尚未验证，不能保证能够正确识别或触发播放。
- 如果修改了音频文件，重新打开应用或重新触发播放即可读取最新文件。
